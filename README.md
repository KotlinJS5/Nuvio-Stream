# Nuvio Stream\n\nA small self-hosted HTTP streaming addon for Nuvio and other Stremio-compatible clients.\n\n## v0.1.0\n\n- Working manifest endpoint\n- Working movie/series stream endpoint\n- IMDb and TMDB-style IDs\n- CORS support\n- Local JSON provider interface\n- No P2P\n\n## Run\n\nRequires Node.js 20+.\n\n```bash\nnpm start\n```\n\nManifest: `http://localhost:7000/manifest.json`\n\n## Add an authorized stream\n\nEdit `streams.json`:\n\n```json\n{\n  "tt1234567": [{\n    "name": "My Provider",\n    "title": "1080p • H.264",\n    "url": "https://your-authorized-host.example/video.mp4"\n  }]\n}\n```\n\nUse only streams you are authorized to access and redistribute.\n\n## Nuvio\n\nAfter deployment, install the public manifest URL in Nuvio, for example `https://your-domain.example/manifest.json`.\n\n## Roadmap\n\nProvider interface, parallel requests, timeouts, quality filtering, per-user configuration, subtitles, caching, and deployment configuration.\n\n## References\n\n- Nuvio: https://github.com/haaihond/Nuvio-Wiki/blob/main/docs/integrations/addons.md\n- Stremio protocol: https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/protocol.md\n
