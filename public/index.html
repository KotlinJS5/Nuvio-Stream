Nuvio Stream

v0.4.0 — authorized HTTP streaming addon for public-domain and Creative Commons sources.

Install

https://nuvio-stream-jfuk-chi.vercel.app/manifest.json

Endpoints

/manifest.json — addon manifest

/health — service health

/stream/movie/<imdb-id>.json — movie streams

/stream/series/<imdb-id>:<season>:<episode>.json — series/local streams
